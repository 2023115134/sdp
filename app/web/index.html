      !
      
ECDHE web mode is a single-computer demonstration.
The backend creates separate logical sender and receiver endpoints and performs a real X25519 exchange in-process. The public keys are not peer-authenticated, so this does not protect against a man-in-the-middle attack and is not a two-computer protocol. It uses no sender password or TCP carrier-bootstrap secret. Existing TCP ECDHE remains separate.
