Metric guide

        
    
          
  • Successful recovery shows the share of trials that fully reconstruct the original plaintext. Use it to judge reliability under real embedding and extraction conditions.
    • 
          
  • Median latency measures the median end-to-end processing time for each benchmark profile. Use it to compare speed while minimizing distortion from a few slow outliers.
    • 
          
  • Embedding throughput reports how many characters the pipeline embeds per second. Use it to estimate scaling and performance for larger payloads.
    • 
          
  • Public carrier size tracks the average generated carrier length. Use it to understand the steganographic overhead and text expansion relative to the secret payload.
    • 
          
  • Auth rejection coverage counts how many integrity-failure checks are blocked. Use it to confirm that tampered ciphertext, mismatched keys, and malformed payloads are actively rejected.

ECDHE demonstration note

        
The backend creates separate logical sender and receiver endpoints and performs a real X25519 exchange in-process. Public keys are not peer-authenticated, so this local demonstration is not a two-computer protocol and does not protect against a man-in-the-middle attack. It uses no sender password or TCP carrier-bootstrap secret. Existing TCP ECDHE remains separate.
